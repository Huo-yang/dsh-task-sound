## 工作区提醒范围与 npm 发布

- 新增“全部会话”与“工作区白名单”两种提醒范围。
- 白名单使用稳定工作区 ID；工作区删除后不会误匹配其他工作区，失效 ID 会在下次保存时清理。
- 子代理任务会话仍不会单独提醒；定时任务按其任务会话所属工作区判断。
- Node.js 最低版本放宽到 22，并移除 DSH 会话与工作区开发包的精确 peer 安装锁。
- 首次发布到 npm，可使用 `dsh plugin --profile web add dsh-task-sound@0.2.0` 安装。

已在 DSH `0.2.0-rc.2`、Node.js 22/24 和 Windows 上验证构建、插件安装、bundle 加载、配置读取保存、工作区过滤和通知行为。Windows 与 Ubuntu CI 均执行完整检查；通知投递仅支持 Windows。

## Workspace notification scope and npm distribution

- Adds all-session and workspace-whitelist notification modes.
- Stores stable workspace IDs and safely handles deleted workspace registrations.
- Continues to suppress subagent completion notifications; scheduled tasks follow their task session workspace.
- Lowers the Node.js minimum to 22 and removes exact installation-time peer locks for development-only DSH session and workspace packages.
- Publishes the plugin to npm for installation with `dsh plugin --profile web add dsh-task-sound@0.2.0`.

Verified with DSH `0.2.0-rc.2`, Node.js 22/24, and Windows for build, installation, bundle loading, settings persistence, workspace filtering, and notification behavior. Full checks run on Windows and Ubuntu CI; notification delivery remains Windows-only.
