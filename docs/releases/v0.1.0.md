## 首个公开版本

- 主 DSH 会话成功完成且达到时长阈值后显示 Windows 通知。
- 自动忽略子代理、失败、取消和未达到阈值的任务。
- 通知标题使用完成会话的会话名；声音由 Windows 通知设置管理。
- 在 DSH 原生插件配置页提供启用开关、最短任务时长和测试提醒。
- 插件名称与简介提供中英文，并跟随 DSH 语言设置切换。

已在 DSH `0.2.0-rc.2`、Node.js 24 和 Windows 上验证插件安装、bundle 加载、配置页、测试通知和主会话完成通知。主会话/子代理过滤、完成原因、时长阈值和去重由自动化测试覆盖。Windows 与 Ubuntu CI 均通过；通知投递仅支持 Windows。

## 安装

下载 `dsh-task-sound-0.1.0.tgz` 和 `SHA256SUMS.txt`，校验后执行：

```powershell
dsh plugin --profile web add "C:\Downloads\dsh-task-sound-0.1.0.tgz"
```

安装后重启 DSH。通知声音取决于 Windows 通知设置、系统音量和专注模式，插件不会额外播放自定义声音。

## Initial public release

Shows a Windows notification after an eligible main-session turn completes, ignores subagent and unsuccessful turns, uses the session name as the title, and integrates configuration with the native DSH plugin page.

Verified with DSH `0.2.0-rc.2`, Node.js 24, and Windows for installation, bundle loading, settings, test notification, and main-session completion notification. Automated tests cover filtering, completion reasons, duration thresholds, and deduplication. Windows and Ubuntu CI passed; notification delivery is Windows-only.
